# Proofnote — see AGENTS.md

The instructions for contributors and their agents live in the tracked root
[`AGENTS.md`](./AGENTS.md): what this repository is, the maturity ladder, what is frozen and
must not be edited in a PR, the honesty bar a contribution must meet, and how
to verify things yourself.

This file is kept as a short pointer rather than a duplicate, on purpose. Two
files that say the same thing slightly differently drift apart the first time
one of them is updated and the other isn't — and by the time that's noticed,
whichever one an agent happened to read was the wrong half. Keeping the real
content in one tracked file and pointing every other entry point at it is the
only version of this that stays true.

Read [`AGENTS.md`](./AGENTS.md).
